Components

Optional pieces for forms, status and feedback, in mydear::components. Below is the gallery example running live: the same C++ as on the desktop, compiled to WebAssembly. Type in the fields, press the buttons, switch the theme.

Drawn by Dear ImGui on a WebGL 2 canvas. Open it full page.
