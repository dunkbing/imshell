Dear ImGui apps, on every platform.

mydear is a small C++20 toolkit around Dear ImGui. You write one frame(); it brings the window, the graphics backend, the frame loop that idles, the title bar, themes and widgets, and the platform pieces in between.

The whole app

A delegate draws a frame; mydear::Run does the rest. The same file builds for every platform above.

#include "mydear/app.hpp"
#include "mydear/button.hpp"

struct Hello : mydear::Delegate {
    int clicks = 0;
    void frame() override {
        const mydear::Rect r = mydear::ContentRect();   // under the title bar, inside the safe area
        ImGui::SetNextWindowPos(r.pos);
        ImGui::SetNextWindowSize(r.size);
        ImGui::Begin("hello", nullptr, ImGuiWindowFlags_NoDecoration);
        if (mydear::Button("Click me", mydear::ButtonVariant::Primary))
            ++clicks;
        ImGui::Text("Clicked %d times", clicks);
        ImGui::End();
    }
};

int main() {
    static Hello hello;
    return mydear::Run({.title = "Hello", .titleBar = true}, hello);
}

What it has

Each part is small and stays out of the way: Dear ImGui is still yours, compiled once by your project.

Platform shell app.hpp

The window, Metal, Direct3D, OpenGL or WebGL, input, and a loop that idles when nothing changes and skips frames identical to the last.

Title bar title_bar.hpp

Draw your own bar in ImGui; mydear keeps the OS buttons, dragging, snap layouts and double-click zoom.

Touch iOS, Android

Tap to click, long press for menus or the text toolbar, drag to scroll with momentum, the soft keyboard and IME.

Native views native_view.hpp

Put a real NSView, UIView, HWND or GtkWidget (a text field, a map, a web view) into the ImGui layout.

Themes & widgets themes.hpp

Eighteen palettes, buttons, selects, toggles, splitters, spinners, menus and modal alerts that all follow the theme.

Components optional

Text fields, cards, badges, callouts, progress, avatars, metrics, chips and toasts, in a separate target you link only if you want them.

Fonts & files fonts.hpp

One UI font from a text font, icon fonts and the system's CJK font; file dialogs; fonts and images baked into the binary.

Auto-update updater.hpp

Sparkle on macOS, WinSparkle on Windows and a checked AppImage swap on Linux, behind one call.

Built for a real app

mydear grew out of DearSQL, a SQL client for desktop, iPad and iPhone, where it runs everything between the operating system and the UI. MIT licensed.
